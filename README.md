# go-path-brute-force

Welcome to my brute force project (with golang)

## Requirements

- Golang :)

## Usage

./brute-force
-h [target host]
-w [wordlist path] (optional)
-cookies [key=value,...] (optional)
-headers [key=value,...] (optional)

## Objective
